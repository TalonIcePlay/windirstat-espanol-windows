# WinDirStat en Español para Windows

**WinDirStat en español para Windows** es una herramienta gratuita y de código abierto para **analizar el espacio en disco**, encontrar archivos grandes y descubrir rápidamente qué está ocupando el almacenamiento de tu PC.

Este proyecto está pensado para usuarios de habla hispana que quieren utilizar WinDirStat en Windows con una experiencia localizada en español, manteniendo las funciones del proyecto original.

## ¿Qué es WinDirStat?

WinDirStat es un **analizador de espacio en disco para Windows** que permite visualizar cómo se utiliza el almacenamiento del ordenador.

El programa analiza discos y carpetas y muestra los resultados mediante una lista de archivos y una representación gráfica Treemap.

La visualización permite identificar rápidamente qué archivos y carpetas están ocupando más espacio.

Si tienes el **disco lleno** y no sabes qué está ocupando tantos GB, WinDirStat puede ayudarte a localizar archivos grandes, carpetas pesadas y otros datos que consumen almacenamiento.

## ¿Por qué utilizar un analizador de disco?

Con el tiempo, las descargas, vídeos, imágenes, copias de seguridad, instaladores y archivos temporales pueden ocupar una gran cantidad de espacio.

Windows ofrece información básica sobre el almacenamiento, pero un analizador de disco permite obtener una visión mucho más detallada.

WinDirStat organiza los datos de forma visual para que puedas encontrar rápidamente dónde se está utilizando el espacio.

## ¿Cuáles son las principales funciones?

* Analizar el espacio utilizado en discos y carpetas
* Visualizar gráficamente el uso del disco
* Treemap para encontrar archivos grandes
* Lista de archivos y directorios
* Ordenación por tamaño y tipo de archivo
* Estadísticas por extensión
* Búsqueda de archivos
* Filtros para analizar el contenido
* Detección de archivos duplicados
* Información detallada sobre el tamaño de los archivos
* Integración con el Explorador de Windows
* Funciones de limpieza
* Compatibilidad con volúmenes NTFS
* Versión portátil disponible en determinadas versiones
* Compatibilidad con Windows 10 y Windows 11

## ¿Cómo analizar el espacio en disco en Windows?

1. Descarga la última versión desde la página de [Releases](../../releases).
2. Instala WinDirStat o utiliza la versión portátil cuando esté disponible.
3. Ejecuta el programa.
4. Selecciona el disco o la carpeta que quieres analizar.
5. Espera a que termine el análisis.
6. Utiliza la lista de archivos y el Treemap para encontrar qué ocupa más espacio.

Después del análisis podrás identificar rápidamente los archivos y carpetas de mayor tamaño.

## ¿Cómo encontrar archivos grandes?

Una vez terminado el análisis, revisa los archivos y carpetas ordenados por tamaño.

El Treemap facilita esta tarea: cuanto más espacio ocupa un archivo o una carpeta, mayor será su área dentro de la visualización.

De esta manera puedes encontrar rápidamente:

* Vídeos grandes
* Archivos ISO
* Instaladores
* Copias de seguridad
* Descargas antiguas
* Archivos temporales
* Carpetas que ocupan demasiado espacio

Antes de eliminar cualquier archivo, asegúrate de que no sea necesario para Windows o para otro programa.

## ¿Cómo liberar espacio en el disco?

Primero utiliza WinDirStat para descubrir qué archivos y carpetas están utilizando más almacenamiento.

Después puedes, por ejemplo:

* Eliminar descargas antiguas
* Borrar archivos temporales
* Eliminar archivos grandes que ya no necesites
* Mover vídeos y fotografías a otro disco
* Archivar documentos
* Desinstalar programas que ya no utilices

Ten especial cuidado con los archivos del sistema y con cualquier archivo cuya función desconozcas.
